# 💡 구현된 영상 처리 개념 상세 분석

이 문서는 `ImageProcessingPerformanceAnalyzer` 프로젝트에 구현된 핵심 영상 처리 알고리즘들의 원리와 두 가지 구현 방식(OpenCV vs. Custom)을 상세히 설명합니다. 각 알고리즘의 목적, 동작 방식, 그리고 코드 레벨에서의 구현 차이점을 통해 심층적인 이해를 돕습니다.

---

## 1. 밝기 조절 (Brightness Adjustment)

### 🔹 개념

이미지의 모든 픽셀에 일정한 상수 값을 더하거나 빼서 전체적인 밝기를 조절하는 가장 기본적인 **점 처리(Point Processing)** 기법입니다. 수식으로는 `Output(x, y) = Input(x, y) + B`로 표현할 수 있으며, 여기서 `B`는 밝기 조절 값입니다.

### 🔹 구현 방식 분석

-   **OpenCV 버전 (`opencv_version`)**:
    -   **코드**: `input.convertTo(result, -1, 1.0, brightness);`
    -   **원리**: OpenCV의 고도로 최적화된 `convertTo` 함수를 사용합니다. 이 함수는 내부적으로 `결과 = α * 원본 + β` 연산을 수행합니다. 밝기 조절에서는 `α` (가중치)를 1.0로, `β` (추가 값)를 `brightness`로 설정하여 모든 픽셀에 `brightness` 값을 효율적으로 더합니다.
    -   **특징**: SIMD(Single Instruction, Multiple Data)와 같은 하드웨어 가속을 활용하여 매우 빠른 속도를 보여줍니다.

-   **직접 구현 (`custom_version`)**:
    -   **코드**: `for` 루프를 사용하여 이미지의 모든 픽셀에 직접 접근하고, 각 픽셀 값에 `brightness` 값을 더합니다.
    -   **원리**: 밝기 조절의 가장 기본적인 원리인 '모든 픽셀에 상수 덧셈'을 순차적으로 구현합니다. `cv::saturate_cast`를 사용하여 연산 결과가 픽셀의 유효 범위(0~255)를 벗어나지 않도록 값을 조정(clamping)하는 과정이 명시적으로 포함됩니다.
    -   **학습 포인트**: 알고리즘의 기초적인 동작 원리를 단계별로 이해할 수 있으며, C++로 이미지 픽셀을 직접 제어하는 방법을 학습할 수 있습니다.

## 2. 감마 보정 (Gamma Correction)

### 🔹 개념

`결과 = 원본^γ` 형태의 비선형(non-linear) 변환을 통해 이미지의 밝기를 조절합니다. 사람의 눈이 밝기를 인지하는 방식이 비선형적이기 때문에, 이를 보정하거나 모니터의 출력 특성에 맞추기 위해 사용됩니다.
-   `γ > 1`: 이미지가 전반적으로 어두워집니다.
-   `γ < 1`: 이미지가 전반적으로 밝아집니다.

### 🔹 구현 방식 분석

-   **OpenCV 버전 (`opencv_version`)**:
    -   **코드**: `cv::pow(result, gamma, result);`
    -   **원리**: 먼저 픽셀 값을 0~255 범위에서 0.0~1.0 범위의 부동소수점 값으로 정규화합니다. 그 후, 행렬 전체에 대해 거듭제곱 연산을 수행하는 `cv::pow` 함수를 호출하여 감마 보정을 적용합니다.
    -   **특징**: 부동소수점 연산을 통해 높은 정확도를 보장하며, OpenCV 내부에서 최적화되어 있습니다.

-   **직접 구현 (`custom_version` - LUT 방식)**:
    -   **코드**: `cv::LUT(input, lut_table, result);`
    -   **원리**: **Look-Up Table (LUT)** 이라는 핵심 최적화 기법을 사용합니다. `std::pow()` 함수는 연산 비용이 매우 비싸기 때문에, 수백만 개의 모든 픽셀에 대해 이 함수를 호출하는 것은 비효율적입니다. 대신, 가능한 모든 입력 값(0부터 255까지)에 대한 감마 보정 결과 값을 미리 계산하여 `lut[256]` 배열에 저장합니다. 그 후, 이미지의 각 픽셀 값을 이 테이블의 '주소'로 사용하여, 미리 계산된 결과 값으로 빠르게 '교체'합니다.
    -   **학습 포인트**: 반복적이고 비용이 큰 연산을 **미리 계산된 테이블 조회**로 대체하여 성능을 극적으로 향상시키는 중요한 최적화 전략을 배울 수 있습니다. 이는 영상 처리뿐만 아니라 다양한 컴퓨팅 분야에서 활용되는 핵심 기법입니다.

## 3. 대비 조절 (Contrast Adjustment)

### 🔹 개념

이미지의 밝은 영역과 어두운 영역의 차이를 조절하여 선명도를 변경하는 기법입니다. 일반적으로 중간 회색 값(128)을 기준으로 픽셀 값의 편차를 증폭시키거나 감소시키는 방식으로 구현됩니다. 수식으로는 `Output = (Input - 128) * C + 128`로 표현할 수 있으며, `C`는 대비 값입니다.

### 🔹 구현 방식 분석

-   **OpenCV 버전 (`opencv_version`)**:
    -   **코드**: `input.convertTo(result, -1, contrast, 0);`
    -   **원리**: 밝기 조절과 동일한 `convertTo` 함수를 사용하지만, 이번에는 `β` (더하는 값)를 0으로 두고 `α` (곱하는 값)를 `contrast` 값으로 설정합니다. 이는 모든 픽셀 값에 `contrast`를 곱하는 것과 같아져, 결과적으로 픽셀 값의 분포를 넓히거나(대비 증가, `C > 1`) 좁히는(대비 감소, `0 < C < 1`) 효과를 냅니다.
    -   **특징**: 곱셈 연산 하나로 대비 조절을 구현하는 효율적인 방식입니다.

-   **직접 구현 (`custom_version`)**:
    -   **코드**: `new_value = (pixel_value - 128) * contrast + 128;`
    -   **원리**: 대비 조절의 수학적 공식을 그대로 코드로 구현했습니다. 각 픽셀 값에서 중간 값인 128을 빼서 중심을 0으로 맞추고, `contrast` 계수를 곱하여 편차를 조절한 뒤, 다시 128을 더해 원래 범위로 되돌립니다.
    -   **특징**: 채널이 1개(그레이스케일)일 때와 3개(컬러)일 때를 `if-else` 문으로 명확히 구분하여, 각각 `at<uchar>`와 `at<Vec3b>`를 사용하여 픽셀에 접근합니다. 이를 통해 알고리즘의 원리를 명확히 보여주면서도 데이터 타입에 따른 메모리 접근 오류를 방지합니다.
    -   **학습 포인트**: 대비 조절의 핵심 원리인 '중심점을 기준으로 한 스케일링(scaling)' 개념을 코드를 통해 직관적으로 이해할 수 있습니다.

## 4. 히스토그램 평활화 (Histogram Equalization)

### 🔹 개념

이미지의 **히스토그램**(픽셀의 밝기 값 분포를 나타내는 그래프)을 분석하여, 특정 영역에 집중된 픽셀 값들을 전체 밝기 범위(0~255)에 걸쳐 균일하게 분포시키는 기법입니다. 이를 통해 이미지의 전체적인 대비를 효과적으로 향상시킬 수 있으며, 특히 너무 어둡거나 밝게 촬영된 이미지의 품질을 개선하는 데 효과적입니다.

### 🔹 구현 방식 분석

-   **OpenCV 버전 (`opencv_version`)**:
    -   **코드**: `cv::equalizeHist(input, result);`
    -   **원리**: 복잡한 히스토그램 평활화의 모든 과정(히스토그램 계산, 누적 분포 함수 생성, 정규화, 픽셀 값 변환)을 단 하나의 함수 호출로 압축하여 제공합니다.
    -   **특징**: 매우 빠르고 안정적이지만, 내부 동작이 추상화되어 있습니다. OpenCV 표준에 따라 그레이스케일 이미지에만 적용 가능합니다.

-   **직접 구현 (`custom_version`)**:
    -   **코드**: 히스토그램 계산부터 이미지 변환까지 알고리즘의 모든 단계를 직접 구현했습니다.
    -   **원리**:
        1.  **히스토그램 계산**: `for` 루프를 통해 이미지의 모든 픽셀을 스캔하여 각 밝기 값(0~255)의 빈도를 계산하여 `hist` 배열에 저장합니다.
        2.  **누적 분포 함수(CDF) 계산**: 계산된 히스토그램을 기반으로 누적 합계를 구해 `cdf` 배열을 만듭니다. CDF는 특정 밝기 값 이하의 픽셀 수를 나타냅니다.
        3.  **변환 함수(LUT) 생성**: CDF를 정규화하여, 각 픽셀의 원래 밝기 값을 새로운 밝기 값으로 매핑하는 변환 테이블(LUT)을 생성합니다. 이 과정이 히스토그램을 '평탄하게' 만드는 핵심입니다.
        4.  **이미지 변환**: 최종적으로 생성된 LUT를 이미지 전체에 적용하여 결과물을 만듭니다.
    -   **학습 포인트**: 통계 기반의 이미지 처리 기법이 어떤 논리적 단계를 거쳐 구현되는지 처음부터 끝까지 상세하게 학습할 수 있습니다. 히스토그램, CDF 등 핵심 개념을 코드로 직접 다루어볼 수 있는 좋은 기회입니다.
