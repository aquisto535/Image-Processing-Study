# 🔬 영상 처리 성능 비교 도구 (Image Processing Performance Analyzer)

## 프로젝트 개요

### 🎯 핵심 목표
- **OpenCV 함수 vs 직접 구현** 성능/정확도 비교
- **TickMeter를 활용한 정밀 성능 측정**
- **다양한 조건에서의 벤치마크 시스템**
- **1월 학습 내용 종합 복습**

### 📚 복습 대상 학습 내용

#### 1. 영상 데이터 구조 및 파일 형식
- **픽셀, 비트맵, 컬러 모델** 이해
- **BMP 파일 구조** (파일 헤더, DIB 헤더, 색상 테이블, 픽셀 데이터)
- **그레이스케일 vs 트루컬러** 차이점
- **Packed-DIB** 개념과 활용

#### 2. OpenCV 기본 사용법
- **Mat 클래스** 활용 (생성, 복사, 접근)
- **기본 자료형 클래스들** (Point, Size, Rect, Scalar)
- **VideoCapture/VideoWriter** 동영상 처리
- **그리기 함수들** (line, rectangle, circle, putText)
- **이벤트 처리** (마우스, 키보드, 트랙바)
- **FileStorage** 데이터 입출력

#### 3. 영상 처리 알고리즘
- **밝기 조절** (`dst = src + n`)
- **명암비 조절** (`dst = src * a`, `dst = src + (src-128)*a`)
- **감마 보정** (`dst = 255 * (src/255)^(1/γ)`)
- **영상 반전** (`dst = 255 - src`)
- **히스토그램** 계산, 스트레칭, 평활화
- **색상 공간 변환** (RGB ↔ HSV ↔ Grayscale)

#### 4. 메모리 관리 및 최적화
- **2차원 배열 동적 할당** 최적화 방법
- **픽셀 접근 방법** (at, ptr, iterator)
- **메모리 효율적 반복문** 작성

### 🚀 프로젝트의 혁신적 특징

#### 1. 이중 구현 방식
```cpp
// 모든 알고리즘을 두 가지 방식으로 구현
class BrightnessAdjustment {
    static cv::Mat opencv_version(const cv::Mat& src, int brightness);
    static cv::Mat custom_version(const cv::Mat& src, int brightness);
};
```

#### 2. 정밀 성능 측정
```cpp
// TickMeter를 활용한 마이크로초 단위 측정
cv::TickMeter timer;
timer.start();
auto result = algorithm_func(input);
timer.stop();
double execution_time = timer.getTimeMilli();
```

#### 3. 다차원 정확도 분석
- **MSE (Mean Squared Error)** 계산
- **PSNR (Peak Signal-to-Noise Ratio)** 측정
- **SSIM (Structural Similarity Index)** 평가
- **히스토그램 유사도** 비교

#### 4. 실시간 성능 모니터링
- 메모리 사용량 실시간 추적
- 성능 트렌드 그래프 표시
- 라이브 벤치마크 모드

### 🎯 학습 효과

#### 1. 이론과 실제의 연결
- 알고리즘 이론을 직접 코드로 구현
- OpenCV 내부 최적화 이해
- 메모리 접근 패턴의 중요성 체감

#### 2. 성능 최적화 감각 개발
- 병목 지점 식별 능력
- 메모리 vs 연산량 트레이드오프 이해
- 실무 수준의 최적화 인사이트

#### 3. 종합적 문제 해결 능력
- 복잡한 시스템 설계 경험
- 성능 분석 및 개선 방법론
- 실측 데이터 기반 의사결정

### 🔧 주요 기술 스택

- **CMake** (크로스 플랫폼 빌드)
- **XML/JSON** (설정 및 결과 저장)
